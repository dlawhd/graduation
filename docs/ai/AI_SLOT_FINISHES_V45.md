# V45 — 다채로운 작은 입구와 더 큰 추억

2026-10-04 현재 로컬 코드·검증 기록이다. 운영 배포 완료를 뜻하지 않는다.

| --- | --- | --- |

기본 테마 저금통 크기·버튼·생성 흐름은 그대로다. 전체/카테고리 모두 기존 6개 페이지 제한과 숫자/화살표 이동을 재사용한다.

## 새 컬렉션

- 포근한 소품: 벙어리장갑, 양말, 목도리, 나비넥타이, 턱받이, 쿠션, 폼폼, 실내화, 단추, 주머니, 하트 패치, 이불.
- 작은 정원: 무당벌레, 달팽이, 새싹, 물뿌리개, 버섯, 도토리, 요정의 집, 꿀벌, 사과, 당근, 해바라기, 팻말.
- 꿈꾸는 장난감: 목욕 오리, 목마, 곰 인형, 공, 기차, 블록, 로봇, 바람개비, 북, 오르골, 스노우볼, 종이배.

36개 모두 고유한 100×100 실루엣과 안전한 쪽지 목표 영역을 갖는다. 기존 자유형과 같은 정사각 기하·크기 공식을 사용한다. 카탈로그 정의는 `cuteSlotCatalog.mjs`, 팔레트는 `slotFinishes.mjs`다.

## 호환·성능·접근성

- 기존 120개 ID를 삭제하거나 재사용하지 않는다. 새 36개를 추가해 서버/DB 허용값은 156개다. 기하/보석 12개는 새 목록에만 없고, 이전에 저장한 저금통·Draft의 표시와 선택 복원은 유지한다.
- V45는 Draft/Design의 두 slot_style CHECK만 확장한다. 컬럼·기본값·기존 행·사진 선택 영역·AI 입력 영역·좌표·인덱스는 바꾸지 않는다. 적용된 V1~V44 마이그레이션은 수정하지 않았다.
- 기존 다섯 컬렉션의 색상 변경과 반사광은 공유 렌더러에 적용되므로 이미 저장한 해당 스타일도 새 색·연출로 표시된다. 실루엣·입구 좌표·사진은 그대로다.
- 반사광은 약 8.6~10.55초 주기 중 짧은 순간에만 나타난다. ID별 시간 분산, 테두리 마스크, pointer-events:none, useId로 격리된 SVG 참조를 사용한다. 구멍이나 쪽지 목표는 움직이지 않는다.
- 도면 탐색은 로컬 DEV 검증 화면에서만 한다. 운영에는 검증한 고정 좌표만 사용한다. 새 타이머·API·DB 조회·AI 호출·라이브러리는 없다.
- 기존 공유 IntersectionObserver와 탭 가시성 관리를 재사용하여 화면 밖/숨긴 탭의 애니메이션을 정지한다. prefers-reduced-motion에서는 반사광을 표시하지 않는다.
- 인증·권한·CSRF·외부 I/O 트랜잭션·중복 저장 방지·Finalize Snapshot은 기존 서비스와 API를 사용한다.

## 실행 결과

- 프론트 관련 Node 회귀 79개 통과, 실패/스킵 0. Vite build 성공.
- 관련 백엔드 981개 통과, 실패/스킵 0. bootJar 성공. 실제 MariaDB 10.11에서 V43/V44 회귀 및 V44→V45 마이그레이션을 검증했다.
- V45 검증은 기존 숨긴 SPIRAL_GATE·위치·크기·사진/AI 입력 영역 보존, 156개 값의 두 테이블 저장, 미지원/NULL/범위 초과 거부를 포함한다.
- 브라우저 실제 SVG 엔진: 자유형 132종 모두 도면 경계·구멍 내부 목표 9점·반사광 주변 9점 통과. 이전 장식 18종도 반사광 테두리 검사 통과. 기본 6종은 좌표 범위와 공용 표시를 별도로 확인한다.
- 1280×720/1024×600에서 선택한 본체 미리보기와 계속 버튼이 뷰포트 안에 보인다. 320px 모바일은 가로 넘침 없이 모든 분류 12개/페이지 6개, 전체 22페이지 표시와 새 입구 저장 안내를 확인했다.
- 실제 FlyingNote를 새 36종에 대해 PC/320px에서 각각 재생했다. 목표 중심과 도착 중심 최대 오차는 각각 약 0.000049px/0.000018px다. 상세 저금통 실제 너비 420px와 쪽지 확인 콜백도 확인했다.
- 밝은/어두운 바탕과 작은 표시에서 색상·반사광을 비교했다. DEV 전용 '반짝임 순간 비교'는 관찰용 정지 화면이며 운영에는 포함되지 않는다.

기존 Vite 500kB 초과 번들 경고 및 deprecated API 경고는 남아 있다.

## 배포 순서와 미확인 사항

V45 및 새 enum을 포함한 백엔드/DB를 먼저 배포하고 Flyway 45 성공을 확인한 뒤 프론트를 배포한다. 새 ID 저장 후 구 enum 백엔드 단독 롤백은 안전하지 않다.

실제 휴대폰 Safari/Chrome과 운영 V45 적용·저장 검증은 별도다. 이번 요청에서 운영 배포·커밋·푸시는 실행하지 않았다.
