## 어떻게 시간을 쟀나?

버튼 클릭 이벤트 처리가 시작된 시점부터 **3D의 흰 사진 자리에 실제 그림이 나타난 최초 기록 캡처**까지를 쟀다. 전환 직후 잠깐 남아 있는 원래 2D 그림, 사진이 없는 흰 입체 표면은 완료로 세지 않았다. 이미지 요청이 끝나도 화면에 사진이 아직 없으면 계속 기다렸다.

각 전환에서 사진이 없는 마지막 캡처와 사진이 보이는 바로 다음 캡처를 직접 확인했다. 일정 간격의 캡처로 관측하므로 실제 사진 표시 순간은 두 캡처 사이에 있다. GPU 작업 완료나 모니터에 표시된 정확한 순간을 측정한 것은 아니다.

두 첫 전환 모두 녹화 중 3D 코드 청크를 요청했다. 모든 브라우저·서버 캐시를 비우거나 백엔드를 재시작한 실행은 아니므로 콜드 스타트 성능으로 발표하지 않는다. 첫 전환과 반복 전환을 분리하고 각 1건이라는 표본 수를 함께 적는다.
