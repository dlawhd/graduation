## 해석의 한계

‘어디에도 키가 없었다’거나 ‘과거에 한 번도 노출되지 않았다’는 보증이 아니다. 검사한 브랜치에서 더 이상 접근할 수 없는 삭제 이력, 포크, GitHub Actions 로그·산출물, 이미지 안의 글자, 서비스 관리자 화면과 외부 저장소는 이번 검사 범위에 포함하지 않았다. 정규식과 GitHub 탐지는 알 수 없는 형식의 비밀값을 놓칠 수 있다. 로컬 설정과의 비교도 식별된 값만 대상으로 했다.

실제 키가 외부에 공개됐다는 별도 증거가 있다면 저장소에서 지우는 것과 별개로 해당 발급처에서 폐기·교체해야 한다. 이번 점검은 키·권한 변경이나 Git 이력 재작성을 수행하지 않았다.
